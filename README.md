# ⚡ IMPULZE — Techfest-Inspired 3D Web Portal

> **Connect. Create. Collaborate. Grow.**  
> A student-driven tech community built to bring together curious minds, passionate learners, and future innovators.

---

## 🌟 Visual & Interactive Features

Inspired by the immersive digital interfaces and WebGL movement of **[Techfest, IIT Bombay](https://techfest.org/)**:

1. **Techfest 3D Quantum Core Engine (`three-scene.js`)**:
   - Central **Quantum Crystal Core** with pulsing emissive shaders and nested icosahedron cages.
   - Segmented **Gyroscopic Tech Rings** rotating on independent axes.
   - **Hyperspace Warpfield** of 2,200+ particles with dynamic depth stretching.
   - Undulating **Cyber Grid Plane** simulating a neon perspective terrain.
   - Floating octahedral data crystals orbiting around the perimeter.
   - **Real-time Cursor Parallax**: Smooth camera tilt and pan responding to mouse & touch movements.
   - **Cinematic Scroll Choreography**: The 3D camera sweeps across angles, diving through rings and zooming as you explore the page.
   - **Interactive 3D Controls**: Drag to rotate in 3D, explode geometry, toggle wireframes, and trigger hyperspace speed.

2. **Cyber Sound Synthesizer (`Web Audio API`)**:
   - Zero-latency procedural futuristic sounds (hover blips, laser confirmation, warp whoosh, terminal typing).
   - Audio Wave visualizer and Mute/Unmute toggle.

3. **"IMPULZE OS" Interactive Cyber Terminal**:
   - Embedded command-line console where visitors can execute commands (`about`, `mission`, `whatsapp`, `insta`, `events`, `warp`, `matrix`, `help`, `clear`) or tap quick chips.

4. **Official Community Links & Modal**:
   - **WhatsApp Community**: Direct invitation link & interactive QR code scanner.
   - **Instagram Handle**: Direct link to `@devimpulze`.
   - The **4 Foundational Pillars**: Connect, Create, Collaborate, Grow.
   - **Programs & Tracks**: Hackathons, Hands-on Workshops, Open Source Labs, and Tech AMAs.

5. **Brand Identity**:
   - Built around the official **IMPULZE** brand logo, featuring neon coral red (`#FF5353`), cyber cream (`#ECE5D8`), deep obsidian (`#06070A`), and cyber cyan (`#00F0FF`).

## 🚀 Quick Start (Running Locally)

### Option 1: Built-in Node Server
```bash
node server.js
```
Then open your browser and navigate to:
```
http://localhost:3000
```

### Option 2: Direct Browser Open
You can also directly open `index.html` in Chrome, Edge, Firefox, or Safari!
